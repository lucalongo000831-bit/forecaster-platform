# KAIRO Official Data Sources

- FRED: series observations and release dates.
- BLS: Public Data API v2 time series; official release mapping is registry work, not inferred data.
- BEA: official API datasets and observations.
- EIA: API v2 energy routes.
- US Treasury Fiscal Data: official public fiscal/interest-rate datasets.
- ECB Data API: SDMX dataflows and series keys.
- Eurostat: Statistics API JSON-stat datasets.
- GLEIF: LEI records and legal-entity matching.
- OpenFIGI: identifier mapping (structured provider; not an issuer authority).
- CFTC Public Reporting Environment: COT and TFF datasets.
- US House Clerk: annual public financial-disclosure document archives.

Official does not mean realtime. Each source retains its own observation, publication and availability semantics. Senate disclosures are not fetched through automation that violates access controls.
